# Omaha Hi-Lo Client

## Обзор проекта

Это клиентское веб-приложение для игры в покер Omaha Hi-Lo, разработанное на Vue.js 3. Приложение предоставляет визуальный интерфейс для симуляции игры с возможностью раздачи карт игрокам и открытия общих карт на столе по этапам игры.

## Технологический стек

- **Vue.js 3.2.35** - JavaScript фреймворк для создания пользовательского интерфейса
- **Vue CLI 4.5.0** - Инструмент для сборки и разработки
- **Sass/SCSS** - Препроцессор CSS для стилизации
- **Babel** - Транспилятор JavaScript
- **ESLint** - Линтер для проверки качества кода

## Функциональность

### Основные возможности

1. **Симуляция покерного стола на 8 игроков**
   - Каждому игроку раздается по 4 карты (стандарт для Omaha)
   - Игроки располагаются вокруг круглого стола

2. **Этапы игры**
   - **Preflop** - раздача карт игрокам
   - **Flop** - открытие 3 общих карт
   - **Turn** - открытие 4-й общей карты
   - **River** - открытие 5-й общей карты
   - **End** - завершение игры

3. **Управление игрой**
   - Кнопка "next" - переход к следующему этапу игры
   - Кнопка "calc" - расчет комбинаций (в разработке)

## Компоненты

### Table.vue
Главный компонент, управляющий игровым процессом.

**Основные методы:**
- `start()` - начало игры, тасование колоды и раздача карт
- `openFlop()` - открытие флопа (3 карты)
- `openTurn()` - открытие терна (1 карта)
- `openRiver()` - открытие ривера (1 карта)
- `endGame()` - завершение игры
- `shuffle()` - тасование колоды
- `bestCombo(cards)` - определение лучшей комбинации карт

**Свойства:**
- `players` - массив игроков (максимум 8)
- `boardCards` - общие карты на столе
- `step` - текущий этап игры

### Seat.vue
Компонент отображения места игрока.

**Принимаемые пропсы:**
- `player` - объект игрока с полями:
  - `name` - имя игрока
  - `cards` - массив карт игрока
  - `combinations` - комбинации (hi/lo)

### PokerCard.vue
Компонент отображения отдельной карты.

**Принимаемые пропсы:**
- `card` - код карты (например, "14s" - туз пик)
- `show` - булево значение для показа/скрытия карты

**Формат карт:**
- Значения: 2-14 (где 14 - туз)
- Масти: s (spades/пики), h (hearts/черви), c (clubs/трефы), d (diamonds/бубны)

## Вспомогательные функции

### cardDeck.js
Создает стандартную колоду из 52 карт.

### shuffle.js
Реализует алгоритм Фишера-Йетса для тасования массива.

### gcd.js
Вычисляет наибольший общий делитель (алгоритм Евклида). Используется для расчета позиций игроков вокруг стола.

### hand.js
Создает хэш руки путем сортировки и объединения карт.

## Правила Omaha Hi-Lo

### Основные отличия от Texas Hold'em:
- Каждому игроку раздается 4 карты (вместо 2)
- Для составления комбинации игрок должен использовать ровно 2 свои карты и 3 общие карты
- Игра идет на "high" (лучшая комбинация) и "low" (самая низкая комбинация)

### Текущее состояние реализации
- ✅ Раздача карт игрокам
- ✅ Открытие общих карт по этапам
- ✅ Визуализация карт и стола
- ⏳ Расчет комбинаций (частично реализован в методе `bestCombo`)
- ⏳ Определение победителей
- ⏳ Реализация правил Low
