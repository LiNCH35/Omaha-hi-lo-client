# Omaha Hi-Lo Client

Клиентское веб-приложение для игры в покер Omaha Hi-Lo с поддержкой машинного обучения для принятия решений.

## Обзор проекта

Omaha Hi-Lo Client — это полнофункциональный симулятор покера Omaha Hi-Lo, разработанный на Vue.js 3. Приложение включает:

- Визуальный интерфейс покерного стола на 8 игроков
- Полный цикл игры (preflop, flop, turn, river)
- Систему оценки стартовых рук
- Интеграцию с нейросетями для принятия решений
- Симуляцию игр с ботом на базе ML

Документация по ML системе: [ml/README.md](ml/README.md)

## Технологический стек

- **Vue.js 3.2.35** — JavaScript фреймворк для UI
- **Pinia 2.0.36** — управление состоянием

## Функциональность

### Основные возможности

- Симуляция покерного стола на 8 игроков
- Раздача карт по этапам (preflop → flop → turn → river)
- Оценка стартовых рук
- Нейросетевой бот для принятия решений
- Расчет комбинаций High и Low
- Поддержка SPR, pot odds и других покерных концепций

### Этапы игры
- **Preflop** — раздача карт игрокам
- **Flop** — открытие 3 общих карт
- **Turn** — открытие 4-й общей карты
- **River** — открытие 5-й общей карты
- **End** — завершение игры

### Компоненты

#### Table.vue
Главный компонент, управляющий игровым процессом.

**Основные методы:**
- `start()` — начало игры, тасование колоды и раздача карт
- `openFlop()` — открытие флопа (3 карты)
- `openTurn()` — открытие терна (1 карта)
- `openRiver()` — открытие ривера (1 карта)
- `endGame()` — завершение игры
- `shuffle()` — тасование колоды
- `bestCombo(cards)` — определение лучшей комбинации карт

**Свойства:**
- `players` — массив игроков (максимум 8)
- `boardCards` — общие карты на столе
- `step` — текущий этап игры

#### Seat.vue
Компонент отображения места игрока.

**Принимаемые пропсы:**
- `player` — объект игрока с полями:
  - `name` — имя игрока
  - `cards` — массив карт игрока
  - `combinations` — комбинации (hi/lo)

#### PokerCard.vue
Компонент отображения отдельной карты.

**Принимаемые пропсы:**
- `card` — код карты (например, "14s" — туз пик)
- `show` — булево значение для показа/скрытия карты

**Формат карт:**
- Значения: 2-14 (где 14 — туз)
- Масти: s (spades/пики), h (hearts/черви), c (clubs/трефы), d (diamonds/бубны)

Основная логика игры.

## Правила Omaha Hi-Lo

### Основные отличия от Texas Hold'em:
- Каждому игроку раздается 4 карты (вместо 2)
- Для составления комбинации игрок должен использовать ровно 2 свои карты и 3 общие карты
- Игра идет на "high" (лучшая комбинация) и "low" (самая низкая комбинация)

### Нейросетевой бот

Бот использует двухступенчатую архитектуру:
1. **Equity Network** — оценивает вероятность победы/поражения
2. **EV Network** — оценивает ожидаемую ценность действий (fold/call/raise)
